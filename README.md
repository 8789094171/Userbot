============================================================
           COMPLETE & ULTIMATE TELEGRAM USERBOT COMMANDS
============================================================
Prefix Default: '.' ya ',' (Apne bot ke hisab se use karein)

------------------------------------------------------------
⚙️ 1. SYSTEM & BOT CONTROL (Bot Chalane Ke Liye)
------------------------------------------------------------
• .alive        - Bot active hai ya nahi aur uski details check karne ke liye.
• .ping         - Server ka response time aur bot ki speed janne ke liye.
• .restart      - Userbot ko restart karne ke liye.
• .update       - Bot ko latest GitHub code ke sath update karne ke liye.
• .shutdown     - Userbot ko poori tarah band karne ke liye.
• .logs         - Bot ke background errors aur working logs dekhne ke liye.
• .usage        - Server (Heroku/Koyeb) ke usage hours aur resource load dekhne ke liye.
• .refresh      - Bina restart kiye saare modules aur permissions wapas reload karne ke liye.

------------------------------------------------------------
👮 2. GROUP ADMIN & MODERATION (Group Control Karne Ke Liye)
------------------------------------------------------------
• .ban          - Kisi user ko group se hamesha ke liye ban karne ke liye.
• .unban        - Ban kiye gaye user ko wapas unban karne ke liye.
• .kick         - Kisi member ko group se turant bahar nikalne ke liye.
• .mute         - Kisi user ko chat me message bhejne se rokne ke liye.
• .unmute       - Mute kiye gaye user ko wapas bolne ki permission dene ke liye.
• .dban         - User ka message delete karke use ban karne ke liye.
• .dmute        - User ka message delete karke use mute karne ke liye.
• .pin          - Kisi message ko chat ke top par pin karne ke liye.
• .unpin        - Pinned message ko unpin karne ke liye.
• .purge        - Jahan reply kiya hai wahan se niche ke saare messages ek sath delete karne ke liye.
• .del          - Kisi ek particular message ko delete karne ke liye.
• .lock <type>  - Group me media, links, ya stickers bhejne par temporary ban lagane ke liye.
• .muteall      - Poore group ki chat ko ek sath lock/mute karne ke liye.
• .unmuteall    - Mute kiye gaye poore group ko ek sath unlock karne ke liye.
• .zombies      - Group me jitne bhi "Deleted Accounts" hain, unhe nikalne (kick) ke liye.
• .unbanall     - Group ke saare banned members ko ek sath unban karne ke liye.

------------------------------------------------------------
🛡️ 3. PM SECURITY & ANTI-PM (Inbox Safe Rakhne Ke Liye)
------------------------------------------------------------
• .pmpermit on  - Inbox me anjaan logo ke aane par automatic warning chalu karne ke liye.
• .pmpermit off - PM security ko poori tarah band karne ke liye.
• .a (Approve)  - Kisi user ko apne inbox me chat karne ki permission dene ke liye.
• .da (Disapprove)- Di gayi permission wapas lene aur user ko fir se block list me dalne ke liye.
• .block        - Kisi user ko direct block karne ke liye.
• .unblock      - Block kiye gaye user ko unblock karne ke liye.
• .allowall     - Inbox me aaye hue saare pending logo ko ek sath approve karne ke liye.
• .disapproveall- Pehle se approved saare users ko ek click me un-approve/block karne ke liye.

------------------------------------------------------------
👑 4. OWNER-ONLY PRIVILEGES (Ultimate Account Control)
------------------------------------------------------------
• .setname <name>- Apne Telegram account ka original display name turant badalne ke liye.
• .setbio <bio> - Apne profile ka main Bio text directly chat se change karne ke liye.
• .setpfp       - Kisi image par reply karke use apni new profile photo banane ke liye.
• .delpfp <count>- Profile se purani photos ko ek sath remove karne ke liye.
• .username <usr>- Apne account ka public Telegram @username update karne ke liye.
• .kickme       - Jis group me aap hain, usse khud ko turant bahar nikalne ke liye.
• .secret       - Bot ke important hidden API keys aur config variables dekhne ke liye.
• .sendas <id>  - Kisi dusre group/channel me bina wahan jaye message send karne ke liye.
• .saved        - Kisi bhi message par reply karke use direct "Saved Messages" me backup karne ke liye.

------------------------------------------------------------
🎵 5. VC MUSIC & AUDIO CONTROL (Voice Chat Me Gaane Bajane Ke Liye)
------------------------------------------------------------
• .play <name>  - YT, Spotify, JioSaavn se gaana dhoodh kar VC me bajane ke liye.
• .vplay <name> - Audio ke sath-sath video gaana bhi live screen par stream karne ke liye.
• .pause        - Chal rahe gaane ko temporary rokne (Pause) ke liye.
• .resume       - Roke hue gaane ko wapas wahin se chalu karne ke liye.
• .skip         - Current gaane ko chhod kar playlist ke agle gaane par jaane ke liye.
• .end          - Voice chat me music ko poori tarah se band karne ke liye.
• .queue        - Aage kaun-kaun se gaane line me lage hain, unki list dekhne ke liye.
• .volume <1-200>- Voice chat me gaane ki aawaz ko dheema ya tez karne ke liye.
• .shuffle      - Queue me lage saare gaano ko aage-piche (Randomize) karne ke liye.
• .loop <on/off>- Ek hi gaane ko baar-baar repeat par chalane ke liye.
• .mutevc       - Bot ki aawaz ko voice chat me temporary mute karne ke liye.
• .unmutevc     - Mute kiye gaye bot ko wapas bajane ki permission dene ke liye.

------------------------------------------------------------
💥 6. SPAM, RAID & PRANK TOOLS (Sirf Masti Aur Fun Ke Liye)
------------------------------------------------------------
• .spam <cnt> <txt>- Ek hi message ko baar-baar fast send karne ke liye.
• .cspam <text> - Text ke har ek letter ko alag-alag message bana kar spam karne ke liye.
• .wspam <text> - Text ke har ek word ko alag-alag message bana kar spam karne ke liye.
• .delayspam    - Khan-pan ya gap (seconds) ke sath ruk-ruk kar spam karne ke liye.
• .bigspam      - Normal spam se bhi bada aur tezi se bulk message bhejne ke liye.
• .raid <cnt> <usr>- Kisi user ke upar back-to-back funny/aggressive messages ki bauchhar ke liye.
• .replyraid on - Kisi user par lagane par, wo jo bhi bolega bot use auto-tag karke target karega.
• .afk <reason> - Offline jaate waqt ise lagayein, tag karne walo ko bot khud reply de dega.
• .hang <count> - Slow devices wale users ki chat screen ko temporary freeze karne ke liye.

------------------------------------------------------------
👤 7. USER CLONING & STEALTH (Nakal Aur Chup Kar Rehne Ke Liye)
------------------------------------------------------------
• .clone <usr>  - Kisi bhi user ka naam, bio aur pfp copy karke uske jaisa banne ke liye.
• .revert       - Cloning hata kar apni real profile wapas lane ke liye.
• .echo <reply> - Samne wala jo bhi likhega, aapka bot wahi same message repeat karega.
• .rmecho       - Echo mode ko band karne ke liye.
• .ghost        - Bina online aaye ya bina "typing..." status dikhaye chupke se chat dekhne ke liye.
• .snipe on/off - Group me koi bhi message delete ya edit karega, bot aapko wo text dikha dega.

------------------------------------------------------------
