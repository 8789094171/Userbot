📌 1. PROFILE & IDENTITY AUTOMATION (Profile Controls)
------------------------------------------------------------
• .setname <First> <Last> - Apne Telegram account ka main display name turant change karne ke liye.
• .setbio <text>         - Apne profile ka bio description seedhe chat se badalne ke liye.
• .setpfp                - Kisi photo par reply karke use new profile picture set karne ke liye.
• .delpfp <count>        - Purani profile photos ko ek sath remove karne ke liye.
• .username <new_user>   - Apne account ka public handle (@username) change karne ke liye.
• .autobio               - Live dynamic bio start karne ke liye (Time/Date automatically update hoga).
• .autoname              - Apne naam ke sath live current time clock emoji automatic add karne ke liye.
• .countpfp              - Apne account par total kitni profile pictures hain wo dekhne ke liye.

📌 2. PRIVACY & ACCOUNT PRIVILEGES (Stealth & Inbox Safety)
------------------------------------------------------------
• .blocklist             - Aapne ab tak jin logo ko block kiya hai unki poori ID list dekhne ke liye.
• .pmpm                  - Kisi specific chat ya user ke liye PM Permit security ko manually toggling karne ke liye.
• .allowall              - PM/Inbox me approval ke liye pending saare users ko ek sath whitelist karne ke liye.
• .kickme / .leave       - Kisi bhi active group se aapka account turant exit/left karne ke liye.
• .ghost                 - Read receipts hide karne aur online status bina show kiye messages padhne ke liye.
• .disapproveall         - Pehle se approved saare users ki permission cancel karke block/warning list me dalne ke liye.
• .privacy               - Apne phone number, last seen aur forward message privacy settings ko check/manage karne ke liye.

📌 3. AUTOMATION, LOGGING & DETECTORS (Self-Triggering Tools)
------------------------------------------------------------
• .autoreply <trig>|<txt>- Kisi specific keyword par automatic predefined reply set karne ke liye.
• .delreply <trig>       - Set kiye gaye kisi automatic reply trigger ko delete karne ke liye.
• .snipe <on/off>        - Chat me agar koi message delete ya edit karega, to bot uska backup text aapko show kar dega.
• .saved / .sv           - Kisi important media/text par reply karke use direct "Saved Messages" me backup karne ke liye.
• .sendas <id> <text>    - Kisi doosre group/channel me bina join kiye apne bot ke through message forward/send karne ke liye.
• .spy <username>        - Kisi target user ki groups me hone wali activities par najar rakhne ke liye tracking trigger.
• .forward <chat_id>     - Selected incoming messages ko kisi doosre destination par automatic route karne ke liye.

📌 4. CORE ENGINE & SERVER SECURITY (Deep Infrastructure Access)
------------------------------------------------------------
• .secret                - Apne userbot ki important API keys, hash aur tokens ko backup dekhne ke liye (Security constraints apply).
• .setvar <name> <value> - Heroku/Koyeb server configuration environment variable change karne ke liye.
• .getvar <name>         - Kisi active dynamic variable ka data fetch karke show karne ke liye.
• .delvar <name>         - Configuration table se kisi data ya value ko erase/default karne ke liye.
• .usage / .dyno         - Server resource health, remaining hours aur system load calculate karne ke liye.
• .cleanall              - Temporary downloads folder, cached logs aur build debris ko complete clear karne ke liye.
• .dbbackup              - Database elements ka ek unified recovery point (.db file) generate karne ke liye.
• .dbrestore             - Kisi pre-existing backup file ko read karke userbot settings recover karne ke liye.
